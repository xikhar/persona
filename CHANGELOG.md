# Changelog

## 0.1.0-beta.0 - In progress

Persona's first beta is under active development.

- Realtime character animation and amplitude-driven lip sync.
- PipeWire, WASAPI process-loopback, and Core Audio process-tap listeners.
- Configurable voice sources with automatic detection, application and Linux
  playback-stream selection, cross-platform regex matching, and external events.
- Transparent desktop presence with manual lifecycle, tray controls, shortcut,
  URL protocol, always-on-top behavior, zoom, orbit, and pan.
- Stateful animation scheduling with varied speaking chunks, configurable
  short-silence handling, smooth crossfades, and one-shot action recovery.
- Reusable VRMA clip library with multi-select action linking, independent
  clip import, preview, download and deletion.
- Optional loopback Kimodo generation with strict SOMA30-to-VRMA conversion,
  semantic and Khronos validation, resumable private jobs, safe errors,
  capacity/storage preflight, Settings controls and opt-in MCP tools.
- Stable, replaceable model and animation slots with a strict release license
  gate.
- Linux, Windows, macOS arm64, and macOS x64 validation and release workflows.
